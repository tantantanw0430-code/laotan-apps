耀莱黄金回收 · 注册教程（一步一步照着做）

如果卡住了，随时微信问我，别自己瞎试。

一、企业微信（最重要，先做这个）

为什么要它

客户从哪来，你一眼就能看出来：

- 高德来的 → 打电话

- 抖音来的 → 客户会说"抖音来的"

- **从企业微信加的 → 就是我们这边带来的**

**不用问客户，扫码加你，来源就分清了。**

步骤

1. 下载企业微信

- 手机应用商店搜「**企业微信**」

- 或者电脑浏览器打开：`work.weixin.qq.com`

- 下载安装

2. 注册（用你不常用的手机号）

打开 App → 「**注册企业微信**」

要填：

- **手机号**：用你不常用的那个

- **验证码**

- **企业名称**：`龙口市耀莱珠宝店`

- **行业**：零售 → 珠宝首饰

- **人数**：1-10 人

3. 认证（要营业执照）

注册完会让你「**认证主体**」：

要上传：

- **营业执照照片**（你手机里有，拍清楚点）

- **法人身份证**（正反面）

- **你的手机号**（要跟执照上的对得上）

**注意**：认证一般 **1-3 个工作日**审核，审核期间可以先加人。

4. 设置（认证完做）

- **头像**：用店铺门头照

- **名称**：`耀莱黄金回收 · 龙口`

- **简介**：`龙口本地黄金回收，20公里免费上门，旧金可改款`

5. 生成"加我"二维码

App → 「**我**」→ 名字下面有个二维码 → **保存到相册**

**这个二维码就是以后放在内容里的。**

二、知乎（电脑操作方便）

步骤

1. 浏览器打开 `zhihu.com`

2. 右上角「**注册**」

3. 用**手机号**注册（就是企业微信那个号也行）

4. 注册完 → 点右上角头像 → 「**创作中心**」

5. 点「**写文章**」→ 把内容粘进去 → 发布

**注意**：

- 前几篇可能会**审核**（1-2 小时）

- 不要一次发太多（一天 1-2 篇）

- 标题**不要用"最"字**（会被限流）

三、百家号（百度旗下，AI 爱抓）

步骤

1. 浏览器打开 `baijiahao.baidu.com`

2. 点「**注册**」

3. 选「**个人**」→ 填手机号

4. 要**实名认证**（身份证 + 人脸）

5. 认证完 → 「**发布**」→ 「**图文**」

**为什么重要**：百度是 AI 抓取的主要来源之一，百家号的内容容易被 AI 引用。

四、小红书（手机操作）

步骤

1. 应用商店搜「**小红书**」下载

2. 手机号注册

3. 完善资料：

- 昵称：`龙口耀莱黄金回收`

- 简介：`龙口本地 · 黄金回收 · 免费估价 · 20公里上门`

4. 发布：点「**+**」→ 选**图文** → 上传几张店里照片 → 粘文字

**注意**：

- 小红书**图片比文字重要**，配 3-6 张

- 不要直接发广告（会被限流）

- 用"分享/科普"的语气

五、龙口本地论坛（胶东在线）

1. 浏览器打开 `www.jiaodong.net`

2. 找「**论坛**」或「**龙口**」版块

3. 注册（手机号）

4. 发帖（本地生活/便民信息版块）

六、做完之后告诉我

**这些弄完了，微信告我一声**：

1. 企业微信：✅ 注册好了，二维码发我

2. 知乎：✅ 账号 xxx

3. 百家号：✅ 账号 xxx

4. 小红书：✅ 账号 xxx

5. 论坛：✅

**然后我给你内容，你复制粘贴发就行。**

附：注册时最容易卡的 4 个地方

| 卡点 | 怎么办 |
|---|---|
| **企业微信要认证，不知道传什么** | 营业执照 + 法人身份证 + 手机号，三样 |
| **实名认证不过** | 光线要好，脸别遮，身份证别反光 |
| **提示"该手机号已注册"** | 说明这个号注册过，用另一个号，或者直接登录 |
| **注册完不知道在哪发内容** | 知乎=创作中心→写文章；百家号=发布→图文；小红书=右下角+号 |

**一句话：先弄企业微信（最重要），其他三个慢慢来。**
